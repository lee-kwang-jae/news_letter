# Project-Scoped Rules for Hanam Newsletter Agent

> **📬 전체 작업 기준서: [NEWSLETTER_GUIDE.md](NEWSLETTER_GUIDE.md)** — 2026-11-10 사용자가 확정한 양식. 새 호는 그 문서의 '매일 작업 순서'대로 만든다. 아래 번호 규칙은 원문이며, 내용이 바뀌면 두 곳을 함께 고친다.

## 1. 지역 정치인 관련 뉴스 수집 및 언급 규칙
하남지역 주요 뉴스 수집 시, 아래에 기재된 의원들의 동정이나 주요 활동이 포함된 뉴스를 우선적으로 발굴하고 뉴스레터 기사 요약문에 해당 의원의 이름을 반드시 명시하여 요약하십시오.

- **하남시의원**: `정혜영`, `최승태`
- **경기도의원**: `오민용`, `강성삼`

## 2. GitHub 배포 규칙 (Git Deployment Rule)
- 기본 작업(뉴스레터 작성 및 수정) 시에는 **로컬 파일 저장**까지만 진행합니다.
- 사용자가 채팅에서 **`/git push`** 라고 명시적으로 명령할 때만 `git push`를 실행합니다.

## 3. 고정 디자인 수칙 (Locked Design System)
- 상단 배너 이미지: `./images/top01.png` (`onerror="this.src='./images/top.png'"` 지참)
- 6대 섹션 순서(이광재 → 지역뉴스 → 맘카페 → 공공기관 → 오늘의 하남일정 → 행사일정 달력), GmarketSansBold 타이틀, 카드 디자인 및 48px 프로필 아이콘(`kjicon.png`)을 엄격히 고정 유지합니다.
- **언론보도·하남 지역 주요 뉴스에는 사진을 넣지 않습니다.** 글로 요점만 정리하고 원문 링크(`기사 원문 보기 (매체) →`)를 겁니다. 이 지침은 바뀌지 않습니다 (2026-11-10 사용자 확정).
- 목차 '📌 우하소 뉴스레터 목차'는 6개 섹션 이름을 **글자로만** 보여 줍니다. 클릭 이동 링크는 넣지 않습니다 (2026-11-10).
- 뉴스레터 이름: `우리동네 하남소식` (2026-09-28 "하남인사이드"에서 변경)
- 메타태그 제목: `매일전하는 이광재의원의 우리동네 하남소식`

## 4. 유튜브 링크 처리 지침 (YouTube Embedding Rule)
- 사용자가 유튜브 링크(Shorts 또는 일반 동영상)를 가져오면 [youtube_embedding_rule.md](rules/youtube_embedding_rule.md) 지침을 **무조건 자동 실행**합니다.
- **요약글 작성 금지**: 텍스트 요약글은 넣지 않고, 오직 영상 플레이어와 '유튜브에서 보기' 링크만 생성합니다.
- `yt-dlp`로 로컬 `.mp4` 동영상 및 포스터 이미지를 자동 다운로드하여 `images/`에 저장하고, 외부 차단(오류 153) 없는 HTML5 `<video>` 플레이어로 현장일지 카드를 구축합니다.

## 5. 타이틀 배너 색상
- 섹션 타이틀 배너는 기본 디자인 `linear-gradient(90deg, #2b6cb0, #4299e1)`을 사용합니다. (추석 특별 디자인은 2026-09-23에 종료)

## 6. 단일 발행 규칙 (Daily Overwrite Rule)
- 뉴스레터는 매일 발행하며, **누적 저장하지 않습니다.** 항상 오늘 호 1개만 존재합니다.
- 이 원칙은 **모든 작업**에 적용됩니다. 수집한 뉴스 데이터(JSON 등), 임시 파일, 이미지, 영상 모두 누적 저장하지 않고 그날 호에 필요한 것만 남깁니다.
- 내일 호가 발행되면 오늘 호와 오늘 호의 소스는 모두 삭제됩니다.
- **양식·메뉴는 매일 동일**합니다. 레이아웃, 6대 섹션 메뉴(행사일정 달력 포함), 디자인은 그대로 두고 **뉴스 내용과 첨부 이미지만 교체**합니다.
- 새 호 발행 시 전날 내용을 지우고 **`index.html` 한 파일에만** 덮어씁니다. (2026-10-07부터 `dashboard/news/index.html` 사본은 만들지 않습니다.)
- `kj_hanam_inside_YYYYMMDD.html` 같은 **날짜별 아카이브 파일을 만들지 않습니다.**
- 이미지도 매일 교체합니다. 새 호 이미지를 넣을 때 전날 호 이미지(기사 사진, 썸네일, 쇼츠 영상/포스터)는 `images/`, `images/today/`에서 모두 삭제합니다.
- 삭제하지 않는 고정 자산: `kjicon.png`, `top01.png`, `top.png`
- 예외: 행사일정 달력 데이터 `events.json`은 한 달치를 누적합니다 (8번 참고).

## 8. 하남 행사일정 달력 (Event Calendar, 2026-11-09 추가)
- 뉴스레터 **맨 마지막 섹션**(공공기관 소식지 다음)에 `📅 하남 행사일정 달력`(#event-calendar)을 **매호 유지**합니다. 목차에도 6번으로 둡니다.
- 데이터 원본은 `events.json` 한 파일입니다. **공공기관 소식지** 기사, **하남시 홈페이지 팝업존**, 사용자가 직접 보내 준 포스터·링크 중 행사 날짜가 있는 것을 넣습니다. (2026-11-10부터 ALL IN 하남라이프 메뉴는 없어졌습니다.) (신청·접수 기간은 `접수일정` 분류로 넣습니다. 채용·할인·설문·제도 안내처럼 시민이 참여할 일정이 아닌 공지는 넣지 않습니다.)
- 분류는 6가지, **이 순서**로, 색은 **항상 고정**: 행사 `#ffd8a8`(파스텔 주황) · 공연.전시 `#d0bfff`(파스텔 보라) · 강의 `#a5d8ff`(파스텔 하늘) · 교육 `#b2f2bb`(파스텔 초록) · 접수일정 `#dee2e6`(연회색) · 기타 `#fcc2d7`(파스텔 분홍) — 2026-11-10 변경: 축제→행사, 공연→공연.전시, 기타 다시 추가, 교육·접수 이름은 '교육'·'접수일정'으로 확정 — 파스텔 바탕에 글자는 진회색 `#2d3748` (2026-11-09 진한 색에서 변경).
  - 교육 = **신청이 아직 열려 있는** 여러 회차 수업·체험 프로그램(접수 마감된 교육은 넣지 않음, `signup` 필수·`signup_end` 지나면 자동 삭제) / 강의 = 한 번 듣는 특강·강연 / 공연.전시 = 공연·연주회·경연대회·전시회 / 행사 = 축제·이벤트 / **기타 = 위에 해당하지 않는 일정**(설명회·박람회·상담회 등) / **접수일정 = 모든 신청·접수·모집 기간**(교육·강의·행사의 접수기간, 이용권·지원사업 신청기간, 위원·참가자 모집). 행사와 접수는 섞지 않습니다.
  - **'접수' 분리 규칙 (2026-11-10)**: 포스터·크롤링 글에 '접수'(신청·모집기간 포함)가 날짜와 함께 나오면 그 기간은 **접수일정**, 본 교육 날짜는 **교육**으로 따로 넣습니다. 마감일 없는 선착순 접수는 접수일정 칩 없이 교육의 `signup` 줄로만 안내합니다. '접수' 말이 없으면 내용을 보고 **강의**(한 번 듣는 특강·강연)와 **교육**(여러 회차 수업·실습·체험)으로 나눕니다.
- 기간이 있는 행사는 start~end 로 넣으면 달력에 **가로막대**로 표시됩니다.
- **요일이 정해진 행사**(예: 매주 금, 화·목)는 `"weekdays": ["금"]` 처럼 넣어 **그 요일에만** 색을 칠합니다. 회차 날짜가 따로 정해진 경우(예: 11.23·24·30)는 `"dates": [...]` 로 그 날만 칠합니다. (2026-11-09 사용자 요청)
- 서로 다른 행사로 안내된 경우(예: 부모교육 11.9·11.23)는 날짜별로 따로 넣어도 됩니다.
- **한 달치 누적**: 이 파일은 단일 발행 규칙(6번)의 예외로 매호 지우지 않고 쌓습니다. 달이 바뀌면 지난달에 끝난 행사만 자동 정리됩니다.
- 매호 순서: 새 기사의 행사를 `events.json`에 추가 → `python -I .agents/tools/build_calendar.py YYYY-MM-DD`(발행일) 실행(검사 + index.html의 `EVENTS-DATA` 사이에 달력 데이터 반영 + `TODAY-SCHEDULE` 사이에 오늘의 하남일정 생성 + 지난달 행사·신청 마감 교육 정리). 다른 날짜로 시험할 때는 `--check`를 붙여 파일을 바꾸지 않습니다.
- 달력 CSS(`/* ---- 행사일정 달력`), 섹션 마크업, 달력 스크립트는 index.html에 고정으로 둡니다. 새 호 본문을 교체할 때 이 부분을 지우지 않습니다.
- **자동 수집 목록 (2026-11-10, 사용자가 정보를 주지 않아도 수집)** — 목록 파일: `.agents/tools/calendar_sources.json`
  1. 하남시 홈페이지 팝업존 (시정 홍보 배너) 2. 하남시 문화행사 안내 3. 하남시 공지사항 4. 하남시보건소 공지사항
  5. 하남문화재단 공연·전시 일정 6. 하남문화재단 공지사항 7. 하남시 평생학습포털 공지사항
  8. 하남시 공식 블로그 하남스토리(RSS)
  - **지정 8곳 외에는 모두 수동 입력입니다.** 사용자가 보낸 링크·포스터·목록 페이지는 그때 한 번 읽어 일정만 넣고, 자동 수집 목록(`calendar_sources.json`)에 추가하거나 예약 작업이 다시 긁지 않습니다. 목록은 사용자가 요청할 때만 바꿉니다 (2026-11-10).
  - **도서관(하남시립도서관 전체)과 하남문화원은 자동 수집하지 않습니다.** 입력자가 직접 정보를 보내 주면 넣습니다 (2026-11-10 사용자 결정).
  - 자동으로 못 읽는 곳(링크를 보내 주면 넣음): 하남시청소년수련관, 하남시가족센터, 하남역사박물관, 네이버 폼.
  - 예약 작업 `hanam-popupzone-calendar-scan`(이름: 하남 행사일정 달력 자동 수집)이 **3일마다 오전 9시**(매달 1·4·7…일)에 `python -I .agents/tools/scan_sources.py`로 새 글만 읽고, 글·포스터를 열어 날짜를 확인한 뒤 6분류로 `events.json`에 넣고 `build_calendar.py 오늘날짜`를 돌립니다. 끝나면 `--mark`로 검토 기록.
  - 검토 기록은 `.agents/tools/sources_seen.json`(출처별 글 번호)이며, 목록에서 내려간 글은 자동으로 지워집니다.
  - 넣지 않는 것: 도서관·하남문화원 프로그램(다른 출처에 나와도 제외), 하남 밖 행사, 채용·봉사자 모집·대관·공모, 할인, 설문·당첨 발표, 성료 보도, 접수가 끝났거나 이미 절반 넘게 진행된 강좌.
  - 출처를 늘리거나 빼려면 `calendar_sources.json`만 고치면 됩니다 (읽는 방식이 같은 게시판이면 parser `egov_bbs` 재사용).
  - 예약 작업은 커밋·푸시를 하지 않습니다. 달력 변경은 사용자가 `/git push` 할 때 함께 배포됩니다.

## 9. 오늘의 하남일정 (2026-11-10, ALL IN 하남라이프 메뉴를 대체)
- `🗓️ 오늘의 하남일정`(#today-schedule, teal 타이틀)은 ALL IN 하남라이프를 대신해 생긴 섹션으로, **5번째(공공기관 소식지 다음, 행사일정 달력 바로 앞)**에 둡니다. 목차 5번. (2026-11-10 사용자 요청으로 공공기관 소식지와 자리 바꿈)
- 내용은 손으로 쓰지 않고, **하남 행사일정 달력(`events.json`)에서 발행일 당일 일정**을 `build_calendar.py`가 자동으로 카드로 만듭니다 (`<!-- TODAY-SCHEDULE:START/END -->` 사이).
  - 그날 열리는 일정(하루 행사·요일 지정·회차 지정·당일 시작)을 먼저, 며칠째 이어지는 기간 행사는 '⏳ 기간 중 진행 중인 일정'으로 아래에 둡니다.
  - 당일 일정이 하나도 없으면 '🔜 다가오는 일정' 3개를 보여 줍니다.
  - "오늘은 일정이 없습니다" 같은 문구는 쓰지 않습니다 (2026-11-10 사용자 요청). 없는 부분은 그냥 생략합니다.
  - 카드 색·아이콘은 달력과 같은 6분류 고정색(행사 🎉 · 공연.전시 🎵 · 강의 🎤 · 교육 📚 · 접수일정 ✍️ · 기타 📌)입니다.
  - **접수일정**는 접수 기간 내내 넣지 않고 **접수 시작일(오늘부터 접수)과 마감일(오늘 마감)에만** 맨 아래 '✍️ 오늘 시작하거나 마감하는 접수'로 보여 줍니다. **달력에서도 접수는 기간 막대 없이 시작일('○○ 시작')과 마감일('○○ 마감', 테두리 강조) 칸에만 표시**하고, 같은 주에서는 행사 줄 아래에 둡니다 (2026-11-10 사용자 요청).
- 발행일이 바뀌면 반드시 `python -I .agents/tools/build_calendar.py 발행일`을 다시 실행합니다.
