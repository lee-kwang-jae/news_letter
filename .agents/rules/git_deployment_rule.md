# 🚀 Git Deployment Rule (Git 배포 수칙)

사용자의 지침에 따라 GitHub 배포(git push)는 아래 규칙을 엄격히 준수합니다.

## 규칙 (Rules)
1. **로컬 작업만 수행**: 뉴스레터 작성, 파일 수정, 로컬 빌드 요청 시 파일 변경 및 로컬 커밋까지만 수행하고, **자동으로 `git push`를 실행하지 않습니다.**
2. **배포 트리거 조건**: 사용자가 채팅으로 **`/git에 배포해`** 라고 명시적으로 명령할 때만 `git push origin main` 명령을 실행하여 GitHub Pages로 배포합니다.
