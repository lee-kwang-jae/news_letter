## 2. 매일 작업 순서

1. **링크 받기** — 사용자가 `현장일지 / 이광재TV / 언론보도 / 하남지역주요뉴스 / 공공기관소식지`(가끔 `공약이행`) 제목 아래 링크를 붙여 준다. 맘카페는 링크가 없으면 직접 수집한다.
2. **내용 읽기** — curl로 원문을 받고, 포스터에만 정보가 있으면 이미지를 내려받아 직접 읽는다. 사실만 쓰고 지어내지 않는다.
3. **전 호 정리** — `images/`의 전 호 기사 사진·썸네일·쇼츠 영상/포스터를 지운다. 남기는 것: `kjicon.png`, `top01.png`, `top.png`.
4. **이미지 저장** — `images/MMDDnn.jpg` (예: 111001, 111002…), 가로 최대 1200px. 사진을 쓰는 곳은 현장일지·공약이행·공공기관 포스터뿐이다 (**언론보도·하남 지역 주요 뉴스는 사진 없음**). 공유 썸네일 `images/thumbnail-MMDD.jpg` 1200×630 (대표 사진을 잘라서).
5. **본문 교체** — 섹션 1~4 카드만 바꾼다. 섹션 5·6과 스크립트·CSS는 그대로 둔다.
6. **머리 정보 갱신** — 배너 아래 `NN호 | YYYY년 M월 D일 발행`, `top01.png?v=MMDD`, og/twitter 이미지 `thumbnail-MMDD.jpg?v=YYYYMMDD01` (5곳 모두).
7. **달력 반영** — 새 호의 공공기관 소식지·사용자가 보낸 행사를 `events.json`에 추가 → `python -I .agents/tools/build_calendar.py YYYY-MM-DD`(발행일). 다른 날짜로 시험할 때는 **반드시 `--check`** 를 붙인다(안 붙이면 그 날짜 기준으로 신청 마감 교육이 실제로 지워짐). 오늘의 하남일정도 이때 자동으로 만들어진다.
8. **확인** — 미리보기(`.claude/launch.json`의 `newsletter`, 포트 8765)로 이미지 깨짐·콘솔 오류·휴대폰 폭(375px) 가로 스크롤 없음 확인.
9. **보고 후 대기** — `/git push`를 기다린다.

## 3. 섹션별 작성 규칙

### 3-1. 우리동네 국회의원 이광재
- **카드 순서**: 📋 공약이행(있을 때만, 맨 앞) → 📝 현장일지 → 🎥 이광재TV → 📰 언론보도
- **제목(h3)**: 항상 **'이광재의원'** 중심. `이광재의원, "…"` / 언론보도는 `[매체] 이광재의원 "핵심 발언"`. '이광재' 단독 표기 금지.
- **공약이행**: `pledge-card` — 제목 아래 상자에는 **글자 없이 가운데 빨간 원형 직인('공약/이행', 둘레에 '우리동네 국회의원 이광재' 회전)**만. 페이지 열고 2초 뒤 '쿵' 찍힘. 그 아래 • 불릿 요약, 사진, `공약이행 전문 보기 (이광재 블로그) →`.
- **현장일지**: `• 요점<br/>• 요점` 불릿 **4~5줄, 300자 이내**, 개조식 끝맺음, 1인칭(제/저) 금지. 사진 1장 + `현장일지 전문 보기 (이광재 블로그) →`.

  - 이광재TV 칸이 비어 있으면 링크를 물어본다 (채널: https://www.youtube.com/channel/UCGQQZrLdCplaD3nktXBdmSw).

- 카드 형식: `1️⃣ [분야] "대표 인용"… 요약 제목` → **현황** → **💡 주민 포인트**(실용 정보, 관련 시 이광재 의원 활동 연결) → **💬 주민 반응** → 📌 출처(카페 이름들).

### 3-4. 🏛️ 공공기관 소식지
- `flex-summary` 카드: 왼쪽 글(굵은 한 줄 인용 → 설명 → 🗓 일시 / 📍 장소 / 👥 대상 / ✍️ 신청 / ☎️ 문의) + 오른쪽 포스터 이미지(240px).
- 링크 문구: `공지 보기 (기관명) →`, 신청 링크가 따로 있으면 `신청하기 →` 추가.
- **네이버 폼(form.naver.com)** 은 내용을 읽을 수 없다 → 제목(og:title)과 카페 검색 등 확인 가능한 사실만 쓰고, 모르는 것은 "신청폼에서 확인"으로 두고 사용자에게 알린다.
- 날짜가 있는 행사·신청은 **달력(`events.json`)에도 넣는다.** (교육은 신청이 아직 열려 있을 때만)

### 3-5. 🗓️ 오늘의 하남일정 (자동)
- `build_calendar.py 발행일`이 `<!-- TODAY-SCHEDULE:START/END -->` 사이를 만든다. **손으로 고치지 않는다.**
- 순서: 그날 열리는 일정(하루 행사·요일/회차 지정·당일 시작) → 기간 중 진행 중인 일정(소제목 없이, 카드에 '진행 중 ·' 표시) → 오늘 시작·마감하는 접수일정(소제목 없이, 카드에 '오늘부터 접수 ·'/'오늘 마감 ·' 표시). 소제목은 하나도 쓰지 않는다 (2026-11-10). 아무것도 없으면 🔜 다가오는 일정 3개.
- "오늘은 일정이 없습니다" 같은 문구는 쓰지 않는다. '이번 달 전체 일정은…' 안내 줄도 넣지 않는다.
- 링크 문구: **`공고원문클릭 →`**

### 3-6. 📅 하남 행사일정 달력
- **데이터**: `events.json` 한 파일. **한 달치 누적**(유일한 예외 — 매호 지우지 않음). 달이 바뀌면 지난달에 끝난 행사는 스크립트가 정리.
- **6분류·고정색** (파스텔 바탕 + 진회색 글자 `#2d3748`)

  | 분류 | 색 | 아이콘 | 넣는 것 |
  |---|---|---|---|
  | 행사 | `#ffd8a8` | 🎉 | 축제·이벤트 |
  | 공연.전시 | `#d0bfff` | 🎵 | 공연·연주회·경연대회·전시회 |
  | 강의 | `#a5d8ff` | 🎤 | 한 번 듣는 특강·강연 |
  | 교육 | `#b2f2bb` | 📚 | **신청이 아직 열려 있는** 교육·강좌·체험 (수업 날짜에 표시) |
  | 접수일정 | `#dee2e6` | ✍️ | 모든 신청·접수·모집 기간 (교육·강의·행사 접수, 이용권·지원사업·위원 모집 등) |
  | 기타 | `#fcc2d7` | 📌 | 위 5개에 해당하지 않는 일정 (설명회·박람회·상담회 등) |

  분류와 범례는 **이 순서(행사 → 공연.전시 → 강의 → 교육 → 접수일정 → 기타)** 로 둔다. (2026-11-10: 축제→행사, 공연→공연.전시, 기타 다시 추가)

- **표시 규칙**
  - 기간 행사는 가로막대. **요일 지정(매주 금, 화·목)은 `"weekdays": ["금"]`**, 회차 날짜는 `"dates": [...]` → 그날만 색칠.
  - **접수일정는 막대 없이 시작일('○○ 시작')·마감일('○○ 마감', 테두리) 칸에만**, 같은 주 행사 줄 아래에.
  - 행사일과 그 접수기간은 **별도 항목**(행사는 행사 분류, 기간은 접수일정).
  - **'접수' 분리 규칙 (2026-11-10)**: 포스터·크롤링 글에 **'접수'(신청기간·모집기간 포함)가 날짜와 함께** 나오면, 그 기간은 **접수일정**에 따로 넣고 본 교육(수업) 날짜는 **교육**에 넣는다. 행사·강의도 같다(행사일은 행사/강의, 접수기간은 접수일정). 마감일 없이 '○일부터 선착순'뿐이면 접수일정 칩은 만들지 않고 교육 카드의 '✍️ 신청' 줄로만 안내한다.
  - **'접수' 말이 없으면** 내용을 보고 직접 나눈다: 한 번 듣는 특강·강연·설명 위주 → **강의**, 여러 회차 수업·실습·체험(만들기 등) → **교육**.
  - **교육 규칙 (2026-11-10)**: 접수가 마감된 교육은 넣지 않는다. 넣을 때는 `signup`(신청 방법·기한 한 줄)을 꼭 적고, 신청 마감일이 정해져 있으면 `signup_end`(YYYY-MM-DD)도 적는다. `signup_end`가 지나면 `build_calendar.py`가 **자동으로 지운다.** 선착순처럼 마감일이 없으면 마감 소식을 들을 때 지운다. 달력 상세·오늘의 하남일정 카드에 '✍️ 신청: …' 줄이 나온다.
- **넣는 출처**: 공공기관 소식지 기사, 사용자가 보낸 포스터·링크, 자동 수집 8곳(아래 4장).
- **넣지 않는 것**: 채용·봉사자 모집·대관·공모, 할인·캐시백, 설문·당첨 발표, 성료 보도, 제도·주의 안내, 하남 밖 행사, 접수가 끝났거나 절반 넘게 진행된 강좌, 끝 날짜가 없는 기간. 같은 행사는 중복으로 넣지 않는다.
- 달력 상세창·카드 링크 문구: **`공고원문클릭 →`**. 달력 위 안내 문장은 두지 않는다.

- **수집 8곳**: ① 하남시 홈페이지 팝업존 ② 하남시 문화행사 안내 ③ 하남시 공지사항 ④ 하남시보건소 공지사항 ⑤ 하남문화재단 공연·전시 일정 ⑥ 하남문화재단 공지사항 ⑦ 하남시 평생학습포털 ⑧ 하남스토리(시 공식 블로그 RSS)
- **자동 수집은 위 지정 8곳뿐이다.** 그 밖의 일정은 사용자가 **수동으로** 링크·포스터를 보내 준다. 사용자가 보낸 링크·목록(복지관, 생활문화센터, 도서관 강좌 목록 등)은 **그때 한 번만 읽어 넣고, 자동 수집 목록에 절대 추가하지 않는다.** 지정 목록은 사용자가 바꾸라고 할 때만 바꾼다. (2026-11-10)
- **수집하지 않는 곳**(사용자가 직접 보내 줌): **모든 하남시립도서관, 하남문화원** — 다른 출처에 나와도 자동으로 넣지 않는다. 기술적으로 못 읽는 곳: 청소년수련관, 가족센터, 역사박물관, 네이버 폼.
- **주기**: 예약 작업 `하남 행사일정 달력 자동 수집 (3일마다)` — **3일에 한 번 오전 9시**(매달 1·4·7…일). 앱이 켜져 있을 때 실행, 꺼져 있었으면 다음 실행 때.
- 예약 작업은 커밋·푸시하지 않는다. 결과는 다음 `/git push` 때 함께 배포된다.
